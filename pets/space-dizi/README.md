# 太空小谛

太空小谛是一只穿着白色太空服、戴猫耳头盔并带着小喇叭的 Codex v2 动画宠物。

## 安装所需文件

- `pet.json`
- `spritesheet.webp`

请保持两个文件位于同一目录。`pet.json` 中的 `spriteVersionNumber` 为 `2`，用于启用 8 x 11 图集和 16 个观察方向。

## 预览与 QA

- `contact-sheet.png`：全部 11 行动画状态预览。
- `look-directions.png`：中性姿态与 16 个观察方向预览。
- `previews/*.gif`：9 个标准动画状态的循环预览。
- `qa/*.json`：结构验证、色键清理、方向语义和最终视觉 QA 记录。

图集规格：`1536 x 2288`、8 列 x 11 行、单元格 `192 x 208`、RGBA WebP。
